# Reference Image Folder

Reference images are the close-up visual evidence used by engineering to define and verify each inspection point.

For the bundled dummy master, Product A / REV-01 contains six reference images:

- `product-a-rev01/screw-01.png` → Screw #1
- `product-a-rev01/screw-02.png` → Screw #2
- `product-a-rev01/screw-03.png` → Screw #3
- `product-a-rev01/screw-04.png` → Screw #4
- `product-a-rev01/screw-05.png` → Screw #5
- `product-a-rev01/screw-06.png` → Screw #6

The application maps each reference image to its corresponding Inspection ROI through `MasterRevision.referenceImages`.
